# Project Context – WhatsApp Farmer Bot

## Stack
- Node.js + Express
- MongoDB + Mongoose
- WhatsApp Cloud API (Meta Graph v25.0)
- Google Apps Script ? Google Sheets
- Render (hosting), UptimeRobot (keep-alive)
- GitHub auto-deploy

## Current State
- Bot receives WhatsApp messages via webhook.
- Saves farmer registration to MongoDB and Google Sheets.
- Has a WhatsApp Flow “Farmer Registration” (draft/pending).
- Env vars: VERIFY_TOKEN, WHATSAPP_TOKEN, PHONE_NUMBER_ID, MONGODB_URI, APPS_SCRIPT_URL, FLOW_ID
